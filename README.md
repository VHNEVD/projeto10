# 📰 TechNews Today - Portal de Tecnologia

Uma página web moderna e responsiva de um portal de notícias sobre tecnologia, desenvolvida com HTML5 e CSS3 puro. O projeto conta com design escuro (Dark Mode), efeito *glassmorphic* no cabeçalho, componentes interativos e layout em grelha responsivo.

---

## 🚀 Funcionalidades

- **Design Moderno e Responsivo**: Layout otimizado para dispositivos móveis e computadores desktop através de CSS Grid e Media Queries.
- **Cabeçalho Glassmorphism**: Utilização de `backdrop-filter` e gradientes para um efeito visual de vidro despolido[cite: 2].
- **Artigos Interativos**: Componente `<details>` do HTML5 para expandir informações sem necessidade de JavaScript.
- **Mídia Incorporada**: Integração de vídeos via `<iframe>` do YouTube.
- **Formulário de Newsletter**: Interface para captura de emails com caixas de seleção, opções e caixa de verificação[cite: 1].
- **Animações Suaves**: Transições com `hover` nos cartões e botões[cite: 2].
